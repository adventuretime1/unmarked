# Roadmap

Unmarked's first release focuses on common, testable cases: recognized Unicode
carriers, safely separable document metadata, and fidelity-gated paraphrasing.

Next areas:

- Run larger evaluations against published statistical watermark schemes and
  multiple detectors.
- Test provider detection endpoints when public access makes reproduction
  possible.
- Compare low-cost lexical, local-model, and remote-model transformations.
- Add stronger semantic, claim, and style fidelity checks.
- Expand supported document formats and local inspection signals.
- Research image and pixel-level signals as a separate pipeline.

Results will name the detector, dataset, threshold, transformation, and sample
size. Unmarked will not turn a narrow evaluation into a universal claim.
